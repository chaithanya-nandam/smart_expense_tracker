# Smart Expense Analytics

Smart Expense Analytics is a modern fintech-style expense management and analytics dashboard built using Next.js, Tailwind CSS, and Recharts.

The application helps users track expenses, analyze spending patterns, manage budgets, and visualize financial insights through interactive dashboards and charts.

## Features

- Add, Edit, and Delete Expenses
- Expense Category Management
- Budget Tracking
- Financial Insights Dashboard
- Interactive Analytics Charts
- Category-Based Expense Analysis
- Search and Filter Transactions
- Responsive Modern UI
- Local Storage Persistence
- Fintech-Inspired Dashboard Design

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Recharts
- Local Storage

## Analytics Included

- Budget Utilization
- Highest Spending Category
- Expense Distribution
- Financial Health Summary
- Category Spending Analysis

## Project Purpose

This project was developed to demonstrate frontend engineering skills, dashboard UI development, analytics visualization, and financial application architecture.
